# Introduction:
Le projet consiste à développer une application web de gestion de bibliothèque. Elle permet de faciliter la gestion des livres et d'organiser les informations dans une seule application.

---


# Besoin:
La gestion manuelle d'une bibliothèque peut entraîner une perte de temps et des difficultés pour organiser les livres.

Le projet répond au besoin de disposer d'un outil informatique simple permettant d'ajouter et de consulter les livres facilement.

--- 

# Analyse
Après l'étude des besoins, les principales fonctionnalités identifiées sont :
- Ajouter un nouveau livre.
- Afficher la liste des livres.
- Organiser les livres par auteur et par genre.
- Récupérer et afficher les données dynamiquement.

---

# Conception
La conception permet d'organiser la structure et le fonctionnement de l'application.
- Diagramme de cas d'utilisation : représente les interactions de l'utilisateur avec l'application.
- Diagramme de classes : représente les principales classes du projet.
- Modèle de données : représente les informations des livres, des auteurs et des genres.
- Architecture : séparation entre Frontend et Backend.

---

# Réalisation
Le projet est réalisé avec les technologies suivantes :
- HTML : structure des pages.
- CSS : mise en forme.
- JavaScript : interactions avec l'utilisateur.
- PHP : traitement des données et API.
- JSON : stockage et échange des données.
> Le prototype permet de tester les principales fonctionnalités, notamment l'ajout et l'affichage des livres.

---

# Conclusion
Ce projet nous a permis de développer une application web pour simplifier la gestion d'une bibliothèque.

Il nous a également permis de mettre en pratique nos connaissances en HTML, CSS, JavaScript et PHP, ainsi que de découvrir la communication entre le Frontend et le Backend.
