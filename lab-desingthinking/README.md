# LAB : DESIGN THINKING

## 1. Présentation

Ce Lab présente le Design Thinking.

Le Design Thinking est une méthode pour comprendre les besoins des utilisateurs et trouver des solutions à leurs problèmes.

## 2. Objectifs du Lab

- Comprendre le Design Thinking.
- Découvrir ses différentes étapes.
- Connaître les outils utilisés.
- Apprendre à trouver des solutions.
- Créer des idées simples et utiles.

## 3. Plan de la présentation

1. Définition du Design Thinking
2. Les objectifs du Design Thinking
3. Les 5 étapes du Design Thinking
4. Les outils du Design Thinking
5. Exemple pratique
6. Conclusion

## 4. Les 5 étapes du Design Thinking

| Étape | Description |
|---|---|
| Empathie | Comprendre les besoins des utilisateurs. |
| Définition | Identifier le problème. |
| Idéation | Chercher plusieurs idées. |
| Prototypage | Créer un premier modèle. |
| Test | Tester et améliorer la solution. |

## 5. Exemple pratique

**Problème :**

Les étudiants ont des difficultés pour trouver des livres dans une bibliothèque.

**Solution :**

Créer une application web pour une bibliothèque.

**Fonctionnalités :**
- Chercher un livre.
- Voir les livres disponibles.
- Trouver un livre facilement.
